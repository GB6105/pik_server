## 막힌 점·이슈
- CI 실패 알림만으로는 시험 실패와 구분되지 않았다. 작업 단계 수 (0개)와 실행 시간 (2초)으로 실행 환경 배정 전 실패임을 확인했다.
- 현재 `gh` 토큰 권한 (`repo`·`read:org`·`gist`)으로는 결제 내역을 읽을 수 없어, 청구 항목은 사용자가 GitHub 결제 화면에서 확인해야 했다.
- `jev-api-check` worktree는 2026-10-26 develop 기준이라 STATUS 차이를 그대로 적용할 수 없었다. 이후 ADR-0033 #7이 "early access 신청"을 남겨 두었으므로, 그 항목은 지우지 않고 호출 확인 사실만 덧붙였다.

## 결정
- D-09 (사용자 결정, [ADR-0033](../adr/0033-later-stage-policy-proposals.md) #6 채택): 첫 출시 = 단말이 `text.status`만 보낸다. 글자는 Claude가 이미지에서 읽는다. OCR 본문 동봉은 D-07 측정에서 이득이 입증되면 상한·검증·동의 항목과 함께 추가한다. 근거: 이득은 측정 전이고, 범위 (본문 상한·검증·최대 비용)와 동의 안내 변경은 확실하다. FR-I-03 "온디바이스와 클라우드의 조합"은 단말 판정 (`text.status`·벡터·축소) + 클라우드 분석으로 충족한다
