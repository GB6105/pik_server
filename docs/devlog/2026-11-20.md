## 막힌 점·이슈
- 설계 2.7이 가정한 "기존 요청 속도 제한 저장소"가 없었다. 입력 속도 표 `analysis_input_rate`를 새로 만들었다.
- 설계 0.3 잠금 순서 (할당 → 일일 → 기기)로는 사진별 `settle`이 한 잠금 아래에서 끝나지 않는다. 주체 일일 송신을 할당 앞으로 옮기고 전이별 잠금 표를 계약으로 두었다.
- 서버는 S3 객체의 물리적 삭제를 확인할 수 없다. 최종 상태를 `DELETE_SENT` (삭제 요청 성공)로 좁히고, 부재는 버킷 수명 주기 3일이 보장한다 (R3-04).
- `anthropic-java` 3.10.0은 API 키를 `Authorization: Bearer`로 보낸다. 실제 API 수락은 첫 실제 호출 (D-07)에서 확인한다.
- IAM에는 `s3:HeadObject` 동작이 없다. HEAD는 `s3:GetObject`로 허용되고, 없는 키 HEAD가 404이려면 `s3:ListBucket`이 필요하다 (B11.2).
