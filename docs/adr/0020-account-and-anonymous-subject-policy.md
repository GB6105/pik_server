# ADR-0020: 계정·비로그인 주체 정책 (P07·P08 일부)

- 상태: 채택 (파생 규칙 확정: ADR-0021, 최소 기록·해시 저장 시점 보완: 2026-10-26)
- 날짜: 2026-10-26
- 관련: FR-A-01~05, FR-B-01, P07, P08, ADR-0014, ADR-0015, ADR-0018, D-01, D-14, 브랜치 `feature/first-fr-plan`

## 맥락
- 계정·게스트 데이터의 관계와 비로그인 주체 식별이 정해지지 않으면, 요청 주체 기준 소유 범위 검증 (CLAUDE.md 불변 규칙)의 공통 기반을 만들 수 없다.
- P07·P08은 범위가 넓다. 이번에는 계정·주체 식별에 필요한 항목만 정한다.

## 결정
### P07 (사용자 결정)
| 항목 | 결정 |
|---|---|
| 게스트 데이터 귀속 (FR-A-02) | 로그인 직후 사용자 확인을 받은 뒤 귀속한다. 태그는 합집합으로 합친다. 같은 사진의 메모·정리 상태가 다르면 서버 값을 유지하고 충돌 목록을 반환한다. 사용자가 고른 값은 일반 수정 요청으로 반영한다 |
| Apple·Google 계정 병합 (FR-A-01) | 제공자별로 별도 계정이다. 첫 출시에는 병합·연결 기능이 없다 |
| 로그아웃 (FR-A-03) | 단말은 계정에 귀속된 메타데이터를 기기에서 지우고 Pro 표시를 해제한다. 다시 로그인하면 서버에서 복원한다. 서버는 해당 세션의 refresh 토큰을 폐기한다 |

### P08 (사용자 결정)
| 항목 | 결정 |
|---|---|
| 비로그인 주체 식별 | 설치마다 서버가 익명 주체 ID와 토큰을 발급한다. 발급할 때 App Attest (iOS)·Play Integrity (Android)로 정상 앱인지 확인한다 |
| 재설치 시 무료 체험 (FR-B-01) | 다시 주지 않는다. 재설치한 기기는 iOS DeviceCheck와 Android ANDROID_ID로 판별한다 |
| 탈퇴 시 남기는 기록 (FR-A-05) | 내부 계정 ID, 탈퇴 일시, 삭제 작업 상태, 처리한 결제 이벤트 ID와 종류 (`type`), 제공자 사용자 ID의 해시만 남긴다. 결제 이벤트 본문은 지운다. 보관 기간은 법령을 검토한 뒤 설정값으로 둔다 |
| 탈퇴 후 재가입 | 체험을 다시 주지 않는다. 제공자 사용자 ID 해시로 재가입을 판별한다. 해시는 가입할 때 저장한다 |

### 파생 규칙 (ADR-0021에서 사용자 확정)
- 체험 이용량은 기기 단위와 계정 단위에 모두 기록하고, 둘 중 하나라도 소진했으면 체험을 주지 않는다. 새 계정으로 로그인하면 그 기기의 게스트 이용량을 이어받는다.
- 기기 판별 기록과 재가입 판별 해시는 탈퇴 후에도 남으므로 계정 데이터와 분리해 저장한다. 원본 식별자는 저장하지 않고, 서버 비밀 키로 만든 HMAC만 저장한다.

## 근거
- 게스트 귀속: 불변 규칙 "다른 주체 데이터 자동 병합 금지"와 FR-A-02의 "임의로 덮어쓰지 않는 안"을 함께 지킨다. 충돌 해소 전용 API 없이 일반 수정 경로를 재사용한다.
- 별도 계정: Apple 이메일 가리기 (private relay) 때문에 이메일 기준 연결이 불안정하고, 자동 병합 금지 규칙과도 맞는다.
- 로그아웃 시 제거: 다음에 다른 계정으로 로그인할 때 이전 계정 데이터가 게스트 데이터로 섞이지 않는다.
- 기기 증명: 앱을 거치지 않고 토큰을 대량으로 발급받아 체험을 남용하는 경로를 막는다.
- 최소 기록: 탈퇴 전에 시작된 작업의 늦은 응답·웹훅이 데이터를 다시 만들지 않도록 판별한다 (FR-A-05).

| 대안 | 버린 이유 |
|---|---|
| 귀속 과정에서 충돌 항목별 선택 | 충돌 해소 API와 복잡한 단말 화면이 추가로 필요 |
| 기존 계정에 데이터가 있으면 귀속 안 함 | 새 기기에서 만든 데이터가 계정에 올라가지 않음 |
| 로그아웃 후 기기 데이터 유지 | 다른 계정으로 로그인할 때 이전 계정 데이터가 섞일 위험 |
| 설치별 토큰만 (기기 증명 없음) | 체험 대량 남용을 막기 어려움 |
| 재설치·재가입 시 체험 재지급 | 사용자 결정 |
| 탈퇴 시 즉시 전부 삭제 | 늦은 응답의 재생성을 판별할 수 없음 |

## 결과
- 기기 판별 정보 (DeviceCheck 상태, ANDROID_ID 해시)와 제공자 사용자 ID 해시가 개인정보 처리 고지 (P08)에 추가된다. 보관 기간은 설정값이다.
- 공장 초기화·기기 변경 뒤의 비로그인 재설치는 막지 못한다. 루팅·탈옥 기기의 ANDROID_ID 조작은 Play Integrity 판정으로 일부만 막는다.
- 새 서버 비밀 값: App Attest·DeviceCheck용 Apple 키, Play Integrity용 Google Cloud 서비스 계정, 식별자 HMAC 키. 도입할 때 `.env.example`에 키를 추가한다 (ADR-0015).
- 계속 미정: PHCloudIdentifier 신뢰성·같은 기기 재설치 복원 방법 (FR-A-04 기술 검증. 기기 간 같은 사진은 iCloud 동기화 사진만 인정: ADR-0022), 정리 세션 복원 범위 (P04와 함께), 임시 보관 기간·동의 철회 (단계 3 전), 탈퇴 시 활성 구독 안내.
- 출처: 결정 표의 항목은 사용자가 정했다 (2026-10-26). 파생 규칙은 Claude가 제안했고 사용자가 ADR-0021에서 확정했다. 결제 이벤트 종류 보존과 가입할 때 해시 저장은 ERD 작업 중 사용자가 추가로 정했다 (2026-10-26, Claude 추천은 탈퇴할 때만 저장).
