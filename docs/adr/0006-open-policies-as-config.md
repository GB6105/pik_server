# ADR-0006: 미정 정책 값은 설정값으로 분리한다

- 상태: 채택
- 날짜: 2026-10-25
- 관련: 커밋 `11fd080`, `.claude/docs/open-policies.md`, 요구사항 `# 미정 정책과 기술 검증`

## 맥락
- 요구사항에 미정 정책 P01~P12가 있다 (예: P01 무료 100장 집계 기준, P09 알림 주기).
- 정책이 확정되기 전에 구현을 시작해야 한다.

## 결정
- 미정 값은 코드에 하드코딩하지 않고 `application.yml` 설정값으로 둔다. 기본값은 현재 초안을 사용한다.
- 인수 조건이 불완전한 FR은 TODO로 남기지 않고 열린 질문으로 보고한다.
- 정책이 확정되면 `open-policies.md` 표와 관련 설정값을 갱신한다.

## 근거
- 정책이 바뀔 때마다 코드를 수정·배포하지 않고 설정만 바꿀 수 있다.
- TODO는 코드에 묻혀 잊히기 쉬우므로, 사용자가 결정해야 할 사항은 질문으로 드러낸다.

## 결과
- 서버 영향 정책: P01~P03, P05, P07~P11. 단말 전용: P04, P06, P12.
