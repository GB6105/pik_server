# ADR-0033: 이후 단계 정책 제안 (구독 처리량·분석 측정·OCR·검색·사진 수렴·보관·알림)

- 상태: 제안 (Codex 비판 검토 R1~R8 수렴, 2026-11-01). #1 RevenueCat 요금제는 채택 (D-12 해소). 가격·보관·노출 값은 사용자 결정 (D-01·D-27)
- 날짜: 2026-11-01
- 관련: FR-B-03·04·05, FR-I-01·03, FR-S-01·02, FR-A-02·04, FR-L-05, FR-N-02, ADR-0016, ADR-0017, ADR-0018, ADR-0019, ADR-0020, ADR-0022, ADR-0024 #9-3·#12-1, ADR-0031

## 맥락
- 단계 6 이후에 필요한 미결 결정 (D-07·D-08·D-09·D-12·D-14·D-20)과 미정 정책 (P02·P03·P08·P09·P10·P11)을 Codex와 검토했다.
- 사용자가 확정한 결정 (Haiku 5.5, RevenueCat, 검색 Basic = Jev·Pro = Jev+LLM, 서버 중심 알림)은 바꾸지 않는다.

## 근거
- 2: REST의 Pro=true만으로 지급하면 복원·TRANSFER로 초기량을 반복해서 받을 수 있다. 확인되지 않은 만료로 거절하면 RevenueCat 장애가 유료 사용자를 막는다 (FR-B-05).
- 3: 장당 비용 $0.00058~0.00081 (Messages, 2026-11-01 추정), Batch는 절반. 손익표는 스토어 15%/30%와 RevenueCat 1%를 넣었다.
- 5: 독립 300건에서 오판 0건이면 오판율의 단측 95% 상한은 약 0.99%다. 모두 `NEEDS_CHECK`로 두어 오판율만 낮추는 설정은 coverage 하한으로 불합격시킨다.
- 10: iOS·Android·Google 포토의 휴지통은 모두 30일이다 (2026-11-01 확인). 서버의 삭제 감지는 실제 삭제보다 늦으므로 여유 5일을 더했다. 30일 안에 복원했어도 35일 뒤에 접속하면 메타데이터를 잃을 수 있으므로 고지한다.

|---|---|

| 5: 불합격 시 자동 Sonnet 상향 | 비용이 바뀌는 결정이므로 사용자 확인 필요 |
| 8: Redis 공유 캐시 | 인스턴스 수가 적고, 캐시가 틀려도 비용만 늘어남 |
