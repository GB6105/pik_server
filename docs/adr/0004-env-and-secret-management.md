# ADR-0004: 환경 변수·비밀 값 관리 방식

- 상태: 채택 (근거 일부 미기록)
- 날짜: 2026-10-25
- 관련: 커밋 `11fd080`

## 맥락
- 로그인(Apple·Google), 플랫폼 결제 검증, 외부 AI 연동 등에서 비밀 값이 필요하다.
- 비밀 값이 저장소나 AI 에이전트의 출력에 노출되면 안 된다.

## 결정
| 환경 | 소스 | git |
|---|---|---|
| 로컬 개발 | `.env.local` | 제외 |
| 배포 서버 | `.env` ← AWS SSM Parameter Store 또는 GitHub Actions secrets 주입 | 제외 |
| 키 목록 공유 | `.env.example` (값 없이 키만) | 포함 |

- `.claude/settings.json`에서 `.env`·`.env.*`의 Read와 `cat`을 deny한다.
- 비밀 값을 코드·설정 파일·커밋에 기록하지 않는다.

## 근거
- 키 목록만 공유하면 값을 노출하지 않고도 필요한 설정을 알 수 있다.
- 에이전트가 `.env`를 읽지 못하게 막아, 대화 기록이나 로그로 값이 새는 경로를 차단했다.
- SSM과 GitHub Actions secrets 중 무엇을 쓸지: **미정**. 배포 환경을 정할 때 새 ADR로 확정한다.

## 결과
- 새 환경 변수를 추가하면 `.env.example`에 키를 추가한다.
