# ADR-0009: 작업 시작·종료 시 결정 사항 보고

- 상태: 채택
- 날짜: 2026-10-25
- 관련: `.claude/docs/decision-reporting.md`, `.claude/hooks/report-open-decisions.sh`, ADR-0007

## 맥락
- 에이전트가 작업을 나누어 진행하면, 어떤 결정을 어떤 근거로 내렸는지와 무엇이 아직 미결인지가 대화 속에 묻힌다.
- 사용자가 결정해야 할 사항을 놓치면 잘못된 가정 위에 구현이 쌓인다.

## 결정
- 작업마다 시작 보고(필요한 결정·추천·근거, 관련 미결 결정)와 종료 보고(내린 결정·근거·기록, 미결 결정)를 한다.
- 미결 결정은 `docs/STATUS.md`의 `## 미결 결정` 표에 `D-NN` ID로 관리한다.
- SessionStart 훅이 미결 결정 표와 보완 대기 ADR을 컨텍스트에 주입한다.

## 근거
| 대안 | 버린 이유 |
|---|---|
| 종료 시에만 보고 | 시작 전에 사용자 결정이 필요한 사항을 놓침 |
| Stop 훅으로 보고 강제 | 응답마다 강제 재실행되어 루프·소음 발생. 작업 단위와 응답 단위가 다름 |
| 미결 결정을 별도 파일로 관리 | STATUS가 진입점이라는 ADR-0007 원칙과 어긋나고, 파일이 늘어남 |

## 결과
- 시작 보고는 규칙(CLAUDE.md)과 SessionStart 훅이 보장하고, 종료 보고는 규칙으로만 보장한다.
