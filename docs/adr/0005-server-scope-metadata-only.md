# ADR-0005: 서버는 Pik 메타데이터만 소유한다

- 상태: 채택
- 날짜: 2026-10-25
- 관련: 커밋 `11fd080`, `.claude/docs/fr-scope.md`, 요구사항 각 FR의 `호출:` 항목

## 맥락
- Pik은 단말의 사진을 정리하는 앱이다. 사진 원본과 실제 앨범은 OS 사진 라이브러리에 있다.
- 요구사항의 FR마다 호출 주체(단말/서버)가 지정되어 있다.

## 결정
- 서버는 사진 원본과 실제 앨범 구성을 소유하지 않고, Pik 메타데이터만 보관한다.
- FR을 서버 전담 / 단말·서버 공동 / 단말 전용으로 분류하고, 단말 전용 FR은 서버에 구현하지 않는다.
- OS 사진 변경·AI 요청·플랫폼 결제는 DB 트랜잭션에 포함하지 않는다.

## 근거
- 요구사항이 FR별 호출 주체를 명시하고 있으므로, 이를 그대로 서버 범위의 기준으로 삼았다.
- 서버가 원본을 갖지 않으면 개인정보 노출 범위와 저장 비용이 줄어든다.
- 서버가 통제할 수 없는 외부 동작을 트랜잭션에 넣으면 롤백할 수 없으므로 분리했다.
