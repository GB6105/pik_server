# ADR-0007: STATUS·ADR·devlog 기록 체계

- 상태: 채택
- 날짜: 2026-10-25

## 맥락
- 진행 상황과 결정 근거를 남겨, 일별로 점검하고 프로젝트 종료 후 회고에 사용해야 한다.
- `.claude/docs/`는 에이전트용 작업 규칙이므로 진행 기록과 섞지 않는다.

## 결정
| 문서 | 경로 | 성격 |
|---|---|---|
| 현황 | `docs/STATUS.md` | 진입점. 최신 상태만 유지 (덮어쓰기) |
| ADR | `docs/adr/` | 결정과 근거. 추가만 하고, 바뀌면 새 ADR로 대체 |
| 일일 기록 | `docs/devlog/YYYY-MM-DD.md` | 날짜별 진행·막힌 점·회고 메모 (추가만) |

## 근거
| 대안 | 버린 이유 |
|---|---|
| 하나의 CHANGELOG에 모두 기록 | 현재 상태를 보려면 전체를 읽어야 하고, 결정 근거가 묻힘 |
| `.claude/docs/`에 기록 | 에이전트 작업 규칙과 섞여 SSOT·보조 문서 체계가 흐려짐 |
| 외부 도구(Notion 등)에 기록 | 코드·커밋과 함께 버전 관리되지 않음 |

- 현재 상태(STATUS), 왜 그렇게 됐는지(ADR), 언제 무엇을 했는지(devlog)를 분리하면 각 질문에 해당 문서 하나만 읽으면 된다.
- devlog의 회고 메모 항목을 모으면 프로젝트 회고 자료가 된다.

## 결과
- 작업 종료 시 STATUS 갱신 + 당일 devlog 작성, 결정이 생기면 ADR 추가.
- CLAUDE.md 보조 문서 표에 기록 규칙 행을 추가했다.
