# ADR-0001: 요구사항 문서를 읽기 전용 SSOT로 둔다

- 상태: 채택
- 날짜: 2026-10-25
- 관련: 커밋 `11fd080`

## 맥락
- 기능 요구사항(FR)과 사용자 시나리오 문서가 구현의 기준이다.
- AI 에이전트가 구현 중에 요구사항 문서를 임의로 수정하면, 구현과 기준이 함께 바뀌어 검증이 불가능해진다.

## 결정
- `docs/spec/`에 요구사항 2종을 두고 SSOT로 지정한다.
- `.claude/settings.json`에서 `docs/spec/**`에 대한 Edit·Write·rm·mv를 deny한다.
- 요구사항과 충돌하거나 누락된 내용을 발견하면 SSOT를 고치지 않고 사용자에게 보고한다.
- SSOT와 보조 문서가 충돌하면 보조 문서를 고친다.

## 근거
- 기준 문서가 하나여야 구현·리뷰·검증이 같은 기준을 본다.
- 규칙만 적어 두면 지켜지지 않을 수 있으므로, 권한 설정으로 수정을 기술적으로 차단했다.

## 결과
- 요구사항 변경은 사용자가 직접 하거나 명시적으로 허용해야 한다.
- 커밋·PR에 구현 대상 FR ID를 명시한다.
