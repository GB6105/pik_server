- 비로그인 사용자도 수동 정리·보관함·메모·태그 등 무료 기능을 이용한다.

- 무료 이용자는 최초 1회 100장 액션·이벤트·기초 검색을 체험하며, 초기 한도는 숨기고 액션·이벤트 합산 3회 클릭 후 구독을 안내한다.

- 대표 분석 재사용과 검색 묶음 표시는 정리의 개별 사진 처리에 적용하지 않는다.

- 삭제는 사진 앱의 보관함 원본 삭제이다. 이벤트 숨김·구성 사진 제외와 원본 삭제는 구분한다.

# 사진 생성과 자동 제시

사진 추가부터 액션·이벤트 생성, 사진 상세·홈 제시까지 사용자의 별도 생성 요청 없이 수행한다.

## G-01 새 사진 감지와 자동 분석 접수

**주어:** 새 사진을 보관함에 추가한 사용자와 Pik

**진입:** 사용자가 촬영·스크린샷·다른 앱 저장·가져오기로 보관함에 정지 사진을 추가한다.

**기능 수행**

1. Pik은 OS 변경을 감지하고 실행·복귀 시 놓친 새 사진을 대조한다. 상세 화면 진입이나 정리 시작은 필요하지 않다.

2. 사진 접근·외부 분석 동의·체험 대상 또는 유효한 Pro 처리량을 확인하고 사진·버전별 작업을 자동 등록한다.

3. 원본 준비 후 OCR·내용·시간·장소·저장 의도를 분석하고 액션 생성과 이벤트 생성을 각각 요청한다.

**종료:** 분석 결과와 사진별 출처가 저장되고 두 생성 작업이 독립적으로 진행된다.

**분기·실패·취소:** OS가 허용하는 실행 시점에 처리하며 앱 종료 상태에서 즉시 실행을 보장하지 않는다. 놓친 사진은 다음 실행·복귀에서 자동 보충한다. 미동의·한도 소진은 신규 분석을 중단하고 기존 결과를 유지한다.

## G-02 액션 자동 생성과 사진 상세 제시

**주어:** Pik과 사진 상세를 여는 사용자

**진입:** Pik이 신규 사진의 분석을 완료하면 해당 사진의 액션 생성 작업을 시작한다.

**기능 수행**

1. Pik은 복사·전화·지도·일정·번역·웹 연결 중 근거가 있는 액션을 자동 추출하고 사진별 문자·번호를 확인한다.

2. 웹 연결은 실제 판매·예매 목적지 탐색을 생성 과정에서 진행한다. 액션 유형·사진 ID·실행 데이터·준비 상태를 저장한다.

3. 사용자가 사진 상세를 열면 저장된 액션을 하단에 제시하고, 화면을 보는 중 준비가 끝나면 갱신한다.

**종료:** 사용자는 상세 화면에서 준비된 액션을 선택한다. 전화·복사·일정 추가·웹 열기는 사용자가 실행할 때 수행한다.

**분기·실패·취소:** 근거가 없으면 액션 없음이 정상이다. 링크 탐색 중·정보 확인 필요·실패를 준비 완료와 구분하며 모호한 후보는 사용자가 선택한다. 이벤트 생성 실패가 액션 성공을 취소하지 않는다.

## G-03 이벤트 자동 생성과 홈 제시

**주어:** Pik과 홈을 보는 사용자

**진입:** Pik이 신규 사진의 분석을 완료하면 이벤트 생성·갱신 작업을 시작한다.

**기능 수행**

1. Pik은 저장 의도·사진의 일정 정보·허용된 캘린더를 바탕으로 관련 사진을 묶을 이벤트 후보를 만든다.

2. 동일한 실제 일정·목적의 기존 이벤트는 연결하고, 없으면 새 이벤트를 저장한다. 사용자의 수정·사진 제외·숨김·완료는 유지한다.

3. 저장된 이벤트를 홈 카드 목록에 반영하고 필요한 시점이 가까운 순과 최근 맥락으로 제시한다. 확인된 시점의 알림은 별도로 예약한다.

**종료:** 사용자는 직접 이벤트를 만들지 않고 홈에서 관련 사진을 확인한다. 날짜 없는 유효한 의도 묶음도 홈에서 볼 수 있다.

**분기·실패·취소:** 날짜가 불명확하면 자동 시간·장소 알림을 예약하지 않는다. 근거가 없으면 생성하지 않는다. 중복 분석으로 같은 이벤트를 복제하거나 숨긴·완료한 이벤트를 되살리지 않는다.

# 첫 사용과 권한

로그인 없이 시작하되 사진 접근과 외부 전송 동의를 구분한다.

## O-01 앱 시작과 사진 전체 접근

**주어:** 처음 방문한 사용자

**진입:** 사용자는 Pik을 처음 실행한다.

**기능 수행**

1. Pik은 사진 관리 목적과 사진 전체 접근이 필요한 이유를 설명한다.

2. 사용자는 사진 전체 접근을 허용한다.

3. Pik은 사진 보관함과 앨범 정보를 불러온다.

**종료:** 사용자는 로그인 없이 초기 설정 또는 메인 화면으로 이동한다.

**분기·실패·취소:** 거절하거나 일부 사진만 허용하면 전체 접근이 필요함을 안내한다. 전체 접근 전 이용 범위와 OS 설정 이동 방식은 상세 설계한다.

## O-02 외부 AI 분석 동의 또는 거절

**주어:** 사진 전체 접근을 허용한 사용자

**진입:** 사용자는 외부 AI 분석 안내를 확인한다.

**기능 수행**

1. Pik은 전송할 사진·추출 정보, 목적과 처리 방식을 설명한다.

2. 사용자는 외부 전송에 동의하거나 거절한다.

3. Pik은 동의 상태에 따라 외부 분석을 사용하거나 중단한다.

**종료:** 동의한 사용자는 분석 기반 체험을 시작한다. 거절한 사용자도 수동 정리·메모·태그를 이용한다.

**분기·실패·취소:** 분석 장애와 전송 미동의를 구분해 안내한다. 이미 생성된 정보의 이용·삭제 및 동의 철회 세부 정책은 후속 설계한다.

## O-03 캘린더·위치 권한 설정

**주어:** 일정·장소 기반 제시를 이용하려는 사용자

**진입:** 사용자는 관련 기능의 안내 또는 권한 설정 화면으로 진입한다.

**기능 수행**

1. Pik은 캘린더·위치의 사용 목적과 허용 시 제공되는 기능을 설명한다.

2. 사용자는 각각의 권한을 허용하거나 거절한다.

3. 미허용 상태에서도 Pik은 사용 가능한 사진 내용·시간 정보로 이벤트를 제시한다.

**종료:** 허용한 권한이 해당 기능에 반영되고, 사용자는 기존 화면으로 돌아간다.

**분기·실패·취소:** Pik은 미허용 권한의 설정을 요청하는 알림을 제공한다. OS 권한창 재요청과 알림 발송을 구분하며 주기·중단 조건은 미정이다.

# 사진 보관함과 앨범

실제 사진은 사진 앱에 연결하고 메모·태그는 Pik에서 관리한다.

## L-01 전체·앨범·태그별 사진 조회

**주어:** 무료 사용자와 Pro 사용자

**진입:** 사용자는 사진 보관함 화면을 연다.

**기능 수행**

1. Pik은 전체 사진과 앨범·태그별 보기, 앨범·태그 조합 조건을 제공한다.

2. 사용자는 원하는 조건과 최신순 또는 오래된순을 선택한다.

3. Pik은 선택한 조건의 사진 목록을 그리드로 표시한다.

**종료:** 사용자는 조건에 맞는 사진을 둘러보거나 상세 화면으로 이동한다.

**분기·실패·취소:** 조건에 맞는 사진이 없으면 빈 상태와 조건 변경 방법을 안내한다. 조회·권한 오류는 실패 사유와 재시도를 제공한다.

## L-02 사진 상세·확대·정보·공유·삭제

**주어:** 무료 사용자와 Pro 사용자

**진입:** 사용자는 보관함·검색·이벤트의 사진을 선택한다.

**기능 수행**

1. Pik은 사진 상세, 날짜 등 기본 정보, 메모와 태그를 표시한다.

2. 사용자는 사진을 확대하거나 정보·공유·삭제 기능을 선택한다.

3. 공유는 OS 공유 화면으로 연결하고 삭제는 보관함 원본 삭제 여부를 확인한다.

**종료:** 사용자는 상세 화면을 계속 보거나 원래 목록으로 돌아간다. 삭제 성공 시 목록도 갱신된다.

**분기·실패·취소:** 공유·삭제 취소 시 사진을 유지한다. 원본 접근·삭제 실패 시 사유를 알리고 완료로 표시하지 않는다.

## L-03 앨범 선택과 새 앨범 생성

**주어:** 사진을 분류하려는 사용자

**진입:** 사용자는 정리 또는 여러 사진 선택 후 앨범 선택을 연다.

**종료:** 선택한 사진과 목적지 앨범이 연결되고, 성공한 이동은 원래 앨범에서 제거·목적지 보관으로 반영된다.

**분기·실패·취소:** 앨범 생성·이동 실패 항목은 미반영으로 남긴다. 스크린샷 스마트 앨범 등 플랫폼별 이동 방식은 기술 검증 대상이다.

## L-04 메모·태그 추가·수정·삭제

**주어:** 무료 사용자와 Pro 사용자

**진입:** 사용자는 정리 중 또는 사진 상세에서 메모·태그 편집을 연다.

2. 사용자는 정보를 추가·수정·삭제하고 저장한다.

3. Pik은 사진에 연결된 정보를 갱신하고 분석·검색용 정보에도 반영한다.

**종료:** 사용자는 수정된 메모·태그를 확인하고 이전 화면으로 돌아간다.

**분기·실패·취소:** 취소하면 기존 입력을 유지한다. 저장 실패 시 입력을 잃지 않도록 실패 사유와 재시도를 제공한다.

# 사진 정리

모든 사진을 개별 처리하고 반영에 성공한 항목만 완료한다.

## C-01 정리할 앨범·작업 단위 선택

**주어:** 사진을 정리하려는 사용자

**진입:** 사용자는 메인 화면의 정리하기 영역으로 진입한다.

**기능 수행**

1. Pik은 최근 정리한 앨범을 기본으로 표시하며 최초에는 스크린샷 앨범을 기준으로 한다.

2. 사용자는 앨범과 50·100·200·300장 중 작업 단위를 선택한다.

3. Pik은 현재 정리 가능한 사진을 한 장씩 제시한다. 검색의 대표 묶음 표시는 적용하지 않는다.

**종료:** 사용자는 선택한 앨범의 개별 사진 정리를 시작한다.

**분기·실패·취소:** 대상 사진이 없으면 빈 상태를 안내한다. 남은 사진이 선택 단위보다 적을 때의 묶음 구성은 상세 요구사항에서 정한다.

## C-02 삭제·앨범 분류·그대로 두기

**주어:** 정리를 진행 중인 사용자

**진입:** 사용자는 현재 정리 카드의 사진을 확인한다.

**기능 수행**

1. 사용자는 왼쪽으로 보내 삭제 대기, 오른쪽으로 보내 앨범 선택을 수행한다.

2. 앨범 선택에는 그대로 두기와 새 앨범 추가가 포함되며 Pro는 적합한 앨범·태그 추천을 받는다.

3. Pik은 선택 결과를 임시 저장하고 다음 사진을 제시한다.

**종료:** 사용자는 다음 사진을 정리한다. 선택은 아직 사진 앱에 확정 반영되지 않는다.

**분기·실패·취소:** 그대로 두기는 해당 앨범의 완료 대상이다. 목적지·기존 다른 앨범의 상태는 자동 완료로 바꾸지 않는다.

## C-03 나중에 정리와 되돌리기

**주어:** 정리를 진행 중인 사용자

**진입:** 사용자는 현재 사진을 미루거나 직전 선택을 바꾸려 한다.

**기능 수행**

1. 사용자는 위 방향에서 다음에·5일 뒤·7일 뒤 중 유예 시점을 선택한다.

2. Pik은 사진을 현재 작업 묶음에서 제외하고 재등장 시점을 기록한다.

3. 사용자는 아래 방향의 되돌리기로 직전 임시 선택을 취소하고 다시 처리한다.

**종료:** 다음에는 다음 정리 세션부터, 5일·7일 유예는 해당 날짜부터 사진이 다시 정리 대상이 된다.

**분기·실패·취소:** 나중에는 정리 완료가 아니다. 되돌리기의 상세 범위와 이미 반영된 결과의 복구는 구분해 설계한다.

## C-04 정리 중단·이어하기·명시적 취소

**주어:** 미완료 정리 작업이 있는 사용자

**진입:** 사용자는 정리를 중단한 뒤 다시 앱 또는 정리 화면을 연다.

**기능 수행**

1. Pik은 미반영 선택과 정리 진행 상황을 임시 저장한다.

2. 사용자는 이전 작업을 이어서 정리하거나 작업 취소를 선택한다.

3. 작업 취소를 선택하면 Pik은 선택한 결과가 사진 앱에 반영되지 않음을 확인한다.

**종료:** 이어하기는 중단 지점에서 재개하며, 취소 확정 시 해당 임시 선택을 반영하지 않고 종료한다.

**분기·실패·취소:** 취소 확인을 닫으면 임시 작업을 유지한다. 중단 시 임시 저장과 최종 반영을 혼동하지 않는다.

## C-05 결과 검토·반영·실패 재시도

**주어:** 정리 결과를 확정하려는 사용자

**진입:** 사용자는 작업 묶음이 끝나면 정리 결과 확인 화면으로 진입한다.

**기능 수행**

1. Pik은 삭제·앨범 분류·그대로 두기·나중에 선택 결과를 모아 보여준다.

2. 사용자는 반영하기를 선택하고 필요한 OS 확인 절차를 수행한다.

3. Pik은 성공한 항목을 실제 사진 앱에 반영하고 사진·앨범 조합의 완료 상태를 갱신한다.

**종료:** 성공한 항목만 완료로 확정된다. 일부 실패가 있으면 사용자는 실패 항목만 재시도한다.

**분기·실패·취소:** 원본 삭제는 보관함 삭제이다. 실패·취소 항목을 성공으로 처리하지 않으며 이미 성공한 항목을 중복 반영하지 않는다.

# 사진 검색과 대표 묶음

무료 기초 검색과 Pro 맥락 검색을 구분한다.

## S-01 무료 기초 검색

**주어:** 무료 체험 또는 무료 상태의 사용자

**진입:** 사용자는 검색 화면에서 검색어·조건을 입력한다.

**기능 수행**

1. Pik은 체험 대상 100장의 날짜·앨범·태그와 Jev 기반 기초 분류 정보를 사용한다.

2. 사용자는 지난달 여행 사진처럼 조건으로 해석 가능한 간단한 자연어를 입력한다.

3. Pik은 해당 범위의 결과를 표시하고 조건 보완·더 찾아보기를 제공한다.

**종료:** 사용자는 검색 결과 또는 빈 상태를 확인하고 사진·묶음을 선택한다.

**분기·실패·취소:** 결과가 없으면 검색어·조건 수정 방법을 안내한다. 기본 메타데이터 검색도 우선 같은 체험 범위로 작성한 설계 가정이다.

## S-02 Pro 맥락 검색·Spotlight 진입

**주어:** Pro 사용자

**진입:** 사용자는 앱 검색 또는 iOS Spotlight 결과를 통해 사진을 찾는다.

**기능 수행**

1. Pik은 정리 여부와 무관한 전체 대상 사진의 내용·의도·맥락으로 검색한다.

2. Pik은 입력 단어가 같지 않아도 유사한 맥락의 사진을 관련성이 높은 순으로 제시한다.

3. 순차 분석 중에는 분석이 완료된 범위부터 제공하고, Spotlight 선택은 해당 Pik 사진 화면으로 연결한다.

**종료:** 사용자는 찾은 사진·묶음의 상세 또는 액션으로 이동한다.

**분기·실패·취소:** 구독 만료 시 Pro 확장 검색·OS 연동을 제한하되 무료 기초 검색은 유지한다. OS 연동의 실제 지원 조건은 기술 검증 대상이다.

## S-03 대표 검색 결과와 묶음 전체 보기

**주어:** 검색 결과를 확인하는 사용자

**진입:** 사용자는 같은 시간대의 유사 사진이 포함된 검색 결과를 본다.

**기능 수행**

1. Pik은 대표만 분석한 결과를 구성 사진에 재사용하며 묶음·대표·구성 사진·분석 출처를 구분한다.

2. Pik은 대표 썸네일 오른쪽 상단에 대표를 포함한 총 사진 수를 숫자로만 표시한다.

3. 사용자가 대표 썸네일을 누르면 Pik은 묶음의 모든 사진을 펼친다.

**종료:** 사용자는 구성 사진을 개별 확인·선택하거나 상세 화면으로 이동한다.

**분기·실패·취소:** 대표의 분석 결과와 사진별 원래 메타데이터·사용자 입력은 구분한다. 시간·유사도·대표 선정·서로 다른 문자 확인 규칙은 후속 설계한다.

## S-04 검색 사진 여러 장 선택·일괄 처리

**주어:** 검색 결과에서 여러 사진을 처리하려는 사용자

**진입:** 사용자는 결과 사진을 길게 누르거나 선택 모드로 진입한다.

**기능 수행**

1. 사용자는 여러 사진을 선택하고 태그 추가·앨범 이동·삭제·리마인드 중 기능을 고른다.

2. Pik은 선택 범위와 필요한 입력·삭제 확인을 제공한다.

3. 사용자는 선택한 작업을 실행하고 결과를 확인한다.

**종료:** 성공한 항목에 작업이 반영되고 목록이 갱신된다.

**분기·실패·취소:** 묶음은 펼쳐서 구성 사진을 확인·선택할 수 있다. 대표 선택을 구성 사진 전체 선택으로 해석할지와 드래그 선택 세부는 후속 설계한다.

# 사진 액션

추출한 정보를 복사하거나 실제 행동의 목적지로 연결한다.

## X-01 사진 속 텍스트·계좌번호 복사

**주어:** 분석 결과가 있는 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 복사 액션을 선택한다.

**기능 수행**

1. Pik은 복사할 텍스트·계좌번호 등 추출 정보를 제공한다.

2. 사용자는 복사를 실행한다.

3. Pik은 복사 성공 여부를 안내한다.

**종료:** 사용자는 복사된 정보를 다른 앱에서 활용하거나 사진 상세를 계속 본다.

**분기·실패·취소:** 텍스트를 찾지 못했거나 복사에 실패하면 사유를 안내한다. 묶음 사진의 서로 다른 번호를 복사하지 않도록 검증해야 한다.

## X-02 전화 연결

**주어:** 전화번호가 추출된 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 전화하기를 선택한다.

**기능 수행**

1. Pik은 추출한 전화번호를 사용자가 확인할 수 있게 제공한다.

2. 사용자는 해당 번호로 연결을 진행한다.

3. Pik은 OS의 전화 연결 절차로 넘긴다.

**종료:** 사용자는 전화 절차를 수행하거나 취소 후 사진 상세로 돌아간다.

**분기·실패·취소:** 번호를 확인하지 못했거나 전화 앱 연결이 실패하면 사유를 안내하고 원래 사진을 유지한다.

## X-03 지도에서 장소 열기

**주어:** 장소·주소가 추출된 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 지도 열기를 선택한다.

**기능 수행**

1. Pik은 사진의 장소·주소를 연결할 지도로 전달한다.

2. 사용자는 연결할 수 있는 지도에서 해당 장소를 확인한다.

3. Pik은 외부 지도와 사진 상세 사이의 이동 경로를 제공한다.

**종료:** 사용자는 장소 확인 후 Pik으로 돌아올 수 있다.

**분기·실패·취소:** 장소가 모호하거나 지도를 열지 못하면 실패 사유와 원본 정보를 제시한다. 지도 앱 선택 방식은 UI flow에서 구체화한다.

## X-04 캘린더에 일정 추가

**주어:** 날짜·시간·장소가 추출된 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 일정 추가를 선택한다.

**기능 수행**

1. Pik은 추출한 일정명·날짜·시간·장소를 확인할 수 있게 제공한다.

2. 사용자는 필요한 내용을 확인하고 일정 추가를 진행한다.

3. Pik은 캘린더의 일정 추가 절차와 성공·취소 결과를 처리한다.

**종료:** 일정 추가 성공을 확인하거나 취소 후 사진 상세로 돌아간다.

**분기·실패·취소:** 권한 미허용·일정 정보 부족·등록 실패를 구분해 안내한다. 외부 캘린더의 실제 쓰기 방식은 플랫폼별로 검증한다.

## X-05 사진 속 텍스트 번역

**주어:** 분석 결과가 있는 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 번역 액션을 선택한다.

**기능 수행**

1. Pik은 사진 속 텍스트를 번역할 대상으로 사용한다.

2. Pik은 번역 결과를 제시한다.

3. 사용자는 결과를 확인하고 사진 상세로 돌아간다.

**종료:** 사용자는 번역을 확인한 상태로 사진 이용을 계속한다.

**분기·실패·취소:** 텍스트가 없거나 번역에 실패하면 사유와 재시도를 제공한다. 언어 선택 등 세부 조작은 후속 설계한다.

## X-06 상품·공연의 실제 웹페이지 열기

**주어:** 상품·공연 등 목적지가 추출된 사진을 보는 사용자

**진입:** 사용자는 사진 상세에서 상품 보기·예매하기 등의 웹 액션을 선택한다.

**기능 수행**

1. Pik은 대상과 의도에 맞는 실제 판매·예매 상세페이지를 찾는다.

2. 적합한 후보가 여러 개이면 Pik은 후보를 보여주고 사용자는 하나를 선택한다.

3. 사용자는 선택한 목적지 웹페이지를 연다.

**종료:** 사용자는 실제 목적지에서 다음 행동을 하거나 Pik으로 돌아간다.

**분기·실패·취소:** 정확한 페이지를 찾지 못하면 실패를 안내하고 대상 정보를 수정해 재시도한다. 일반 검색 결과 화면으로 대체하지 않는다.

# 필요한 사진과 이벤트

시점이 명확한 이벤트와 날짜 없는 관심 사진을 구분한다.

## E-01 이벤트 카드·시간·장소 알림으로 진입

**주어:** 이벤트 제시를 이용하는 사용자

**진입:** 사용자는 메인 이벤트 카드를 선택하거나 허용된 이벤트 알림을 연다.

**기능 수행**

1. Pik은 사진의 정보·의도·일정 및 허용된 캘린더를 바탕으로 관련 사진을 모은다.

2. 가까운 시일에 필요한 이벤트를 우선하고 최근 추가된 사진의 맥락을 반영한다.

3. 날짜·시간이 확인된 이벤트는 필요한 시점에 시간·장소 기반 알림으로 제공한다.

**종료:** 사용자는 이벤트의 일정·정보·사진을 확인한다.

**분기·실패·취소:** 시점이 불명확한 이벤트는 메인 카드로만 제시한다. 사용자가 직접 설정한 리마인드는 별도로 제공한다.

## E-02 이벤트 수정·사진 제외·숨김

**주어:** 자동 제시된 이벤트를 교정하려는 사용자

**진입:** 사용자는 이벤트 상세에서 수정·사진 제외·숨김을 선택한다.

**기능 수행**

1. 사용자는 이름·날짜를 수정하거나 잘못 묶인 사진을 제외한다.

2. Pik은 이벤트 정보와 구성 사진을 갱신한다.

3. 사용자가 숨김을 선택하면 Pik은 해당 이벤트를 제시 대상에서 제외한다.

**종료:** 사용자는 수정된 이벤트를 보거나 메인 화면으로 돌아간다.

**분기·실패·취소:** 사진 제외·이벤트 숨김을 원본 사진 삭제로 처리하지 않는다. 변경 실패 시 기존 상태와 사유를 안내한다.

## E-03 이벤트 완료와 전체·일부 삭제 또는 보관

**주어:** 이벤트를 마친 사용자

**진입:** 사용자는 이벤트 상세에서 완료를 선택한다.

**기능 수행**

1. Pik은 완료 여부를 확인한 뒤 관련 사진을 삭제할지 묻는다.

2. 사용자는 전체 삭제·일부 사진 선택 삭제 또는 보관을 선택한다.

3. Pik은 확인한 삭제만 수행하고 이벤트 완료 상태를 유지한다.

**종료:** 이벤트를 완료하고 해당 이벤트 알림·삭제 요청을 종료한다. 보관을 선택해도 완료 상태는 유지한다.

**분기·실패·취소:** 삭제 거절·중간 취소를 자동 삭제 후보로 넘기지 않는다. 삭제 실패 항목은 성공으로 표시하지 않는다.

# 알림과 리마인드

사진 재확인, 정리 독려, 권한 설정 요청을 구분한다.

## N-01 사진 리마인드 설정·알림 열기

**주어:** 사진을 나중에 다시 보려는 사용자

**진입:** 사용자는 사진 상세 또는 여러 사진 선택에서 리마인드를 선택한다.

**기능 수행**

1. 사용자는 다시 볼 시점을 지정한다.

2. Pik은 해당 사진과 시점을 연결해 리마인드를 설정한다.

3. 알림을 받을 수 있는 상태에서 사용자가 알림을 열면 해당 사진·선택 범위로 연결한다.

**종료:** 사용자는 지정한 사진을 다시 확인한다.

**분기·실패·취소:** 알림 미허용·설정 실패 시 사유와 권한 안내를 제공한다. 리마인드를 예약 삭제로 처리하지 않는다.

## N-02 남은 사진 정리 알림과 이어하기

**주어:** 정리할 사진이 남아 있는 사용자

**진입:** 사용자는 Pik의 정리 독려 알림을 선택한다.

**기능 수행**

1. Pik은 남은 정리 대상과 마지막 이용 상황에 따라 알림 시점·내용을 조정한다.

2. 사용자는 알림을 열어 메인 또는 해당 정리 작업으로 이동한다.

3. 미완료 작업이 있으면 사용자는 임시 저장된 지점에서 이어간다.

**종료:** 사용자는 남은 사진을 정리하거나 메인으로 돌아간다.

**분기·실패·취소:** 원안의 1·2·3·5·7·14일 간격은 검토 입력이다. 실제 초기화·중단·수신·재발송 조건은 상세 요구사항에서 확정한다.

## N-03 권한 설정 요청 알림 확인

**주어:** 캘린더·위치 권한을 허용하지 않은 사용자

**진입:** 사용자는 권한 설정을 요청하는 알림 또는 앱 내 안내를 연다.

**기능 수행**

1. Pik은 어떤 기능이 제한되고 권한을 허용하면 무엇을 제공하는지 설명한다.

2. 사용자는 권한 설정을 진행하거나 안내를 닫는다.

3. Pik은 허용 상태를 갱신하고 미허용 상태에서는 가능한 정보로 계속 제시한다.

**종료:** 사용자는 기존 기능 이용을 계속하며 허용한 권한만 반영된다.

**분기·실패·취소:** 이는 권한 허용을 요청하는 알림이라는 사용자 결정을 반영한다. 반복 발송의 주기·중단 및 OS 알림 권한은 별도 설계한다.

# 계정과 데이터

Apple·Google 계정과 사진별 Pik 정보의 보존·삭제를 다룬다.

## A-01 간편 회원가입·로그인

**주어:** 정보를 이어 쓰거나 구독하려는 사용자

**진입:** 사용자는 계정 화면 또는 구독 안내에서 로그인을 선택한다.

**기능 수행**

1. 사용자는 Apple·Google 중 로그인 수단을 고르고 인증을 진행한다.

2. Pik은 기존 계정을 연결하거나 최초 이용자의 계정을 생성한다.

3. Pik은 로그인 상태와 저장된 정보를 반영한다.

**종료:** 계정 화면에서 시작한 사용자는 해당 화면으로, 구독을 진행하던 사용자는 구독 흐름으로 돌아간다.

**분기·실패·취소:** 인증 취소·실패 시 로그인 없이 이용 가능한 기본 기능은 유지한다. 이메일·비밀번호 회원가입은 이번 범위에 추가하지 않는다.

## A-02 로그아웃

**주어:** 로그인한 사용자

**진입:** 사용자는 계정 화면에서 로그아웃을 선택한다.

**기능 수행**

1. Pik은 현재 로그인 세션을 종료한다.

2. Pik은 로그인 상태와 계정 표시를 갱신한다.

3. 사용자는 비로그인으로 가능한 기본 기능을 계속 이용한다.

**종료:** 사용자는 로그아웃된 상태로 계정 화면 또는 메인에 남는다.

**분기·실패·취소:** 로그아웃 뒤 기기 메타데이터 잔존과 구독 권한 표시의 세부 정책은 미정이다. 로그아웃과 회원 탈퇴를 같은 동작으로 처리하지 않는다.

## A-03 기기 변경·재설치 후 정보 복원

**주어:** 새 기기 또는 재설치한 Pik에 로그인한 사용자

**진입:** 사용자는 사진 전체 접근을 허용하고 기존 계정에 로그인한다.

**기능 수행**

1. Pik은 서버의 메모·태그·정리 상태·분석 결과를 불러온다.

2. Pik은 기기 보관함의 동일 사진을 식별해 해당 정보를 다시 연결한다.

3. 사용자는 연결된 정보를 사진 상세·정리·검색에서 확인한다.

**종료:** 사용자는 같은 사진의 Pik 정보를 이어서 이용한다.

**분기·실패·취소:** 원본 사진 백업은 제공하지 않는다. 같은 사진이 없거나 식별에 실패하면 미연결 상태를 알리고 임의 사진에 붙이지 않는다.

## A-04 회원 탈퇴

**주어:** Pik 계정을 삭제하려는 사용자

**진입:** 사용자는 계정 화면에서 회원 탈퇴를 선택한다.

**기능 수행**

1. Pik은 삭제되는 메모·태그·정리 상태·분석 결과와 유지되는 사진·앨범을 설명한다.

2. 사용자는 탈퇴를 최종 확인하거나 취소한다.

3. 확인 시 Pik은 서버·기기의 Pik 정보를 삭제하고 계정을 종료한다.

**종료:** 회원 탈퇴가 완료되며 사진 앱의 사진과 앨범은 유지된다.

**분기·실패·취소:** 취소 시 기존 계정을 유지한다. 실패하면 완료로 표시하지 않는다. 활성 구독의 안내·처리와 데이터 삭제 세부 시점은 후속 설계한다.

# 무료 체험과 Pro 구독

3회 이용 후 구독을 안내하며 닫아도 무료 기능은 유지한다.

## B-01 체험 이용·3회 클릭 후 구독 안내

**주어:** 무료 체험 중인 사용자

**진입:** 사용자는 한도가 노출되지 않은 상태에서 사진 액션·이벤트를 이용한다.

**기능 수행**

1. Pik은 최초 1회 100장 범위에서 액션·이벤트와 무료 기초 검색을 제공한다.

2. 사용자가 액션·이벤트를 합산 3번 클릭하면 Pik은 100장 무료 분석 범위를 설명한다.

3. Pik은 추가 사진의 지속 분석·액션·이벤트, 확장 검색·추천 등 Pro 가치를 안내한다.

**종료:** 사용자는 구독을 진행하거나 닫고 무료 정리·기존 결과·무료 기초 검색을 계속 이용한다.

**분기·실패·취소:** 초기 화면에 100장 한도·잔여량을 노출하지 않는다. 실제 완료량과 다른 분석 완료 문구를 사용하지 않으며 중복·실패 집계는 미정이다.

## B-02 월간·연간 Pro 구독 시작

**주어:** Pro 이용을 선택한 사용자

**진입:** 사용자는 구독 안내에서 Pro 시작을 선택한다.

**기능 수행**

1. 사용자는 월간·연간 중 구독 주기를 선택하고 필요한 경우 Apple·Google로 로그인한다.

2. 사용자는 플랫폼 결제 절차에서 구독 내용을 확인하고 결제를 진행한다.

3. 성공 시 Pik은 Pro 권한을 반영하고 최근 추가·정리 사진을 우선 분석한다.

**종료:** 사용자는 처리량 제한 내 지속 분석, 전체 대상 확장 검색과 앨범·태그 추천을 이용한다.

**분기·실패·취소:** 가격·최초·일별 분석량은 실측 후 정한다. 결제 취소·실패·권한 확인 지연 시 임의로 Pro 완료 처리하지 않는다.

## B-03 구독 상태 확인·관리·구매 복원

**주어:** 구독 상태를 확인하거나 복원하려는 사용자

**진입:** 사용자는 계정 화면에서 구독 관리 또는 구매 복원을 선택한다.

**기능 수행**

1. Pik은 현재 구독 상태와 관리·복원 경로를 제공한다.

2. 사용자는 플랫폼 구독 관리 또는 구매 내역 복원을 진행한다.

3. Pik은 확인된 구매·구독 권한을 계정과 앱 이용 상태에 반영한다.

**종료:** 사용자는 확인된 상태로 계정 화면에 돌아와 기능을 이용한다.

**분기·실패·취소:** 복원할 구매가 없거나 확인에 실패하면 사유와 재시도를 안내한다. 관리 화면 진입만으로 상태가 바뀌었다고 표시하지 않는다.

## B-04 무료 한도 소진·구독 만료 후 이용

**주어:** 무료 한도를 소진했거나 Pro가 만료된 사용자

**진입:** 사용자는 기존 사진 또는 신규·확장 기능을 이용하려 한다.

**기능 수행**

1. Pik은 미분석 사진의 신규 분석과 Pro 확장 검색·OS 검색 연동을 중단한다.

2. Pik은 기존 액션·이벤트, 무료 범위의 기초 검색과 수동 정리를 유지한다.

3. 사용자가 다시 구독하면 Pik은 확인된 권한에 따라 분석·확장 기능을 재개한다.

**종료:** 사용자는 유지되는 무료 기능을 이용하거나 재구독 후 Pro를 이어간다.

**분기·실패·취소:** 기존 액션 이용 유지와 새로운 실시간 웹 탐색 비용은 구분해 설계한다. 무료 제공량은 매달 초기화하지 않는다.
