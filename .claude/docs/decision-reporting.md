# 결정 사항 보고

근거: `docs/adr/0009-decision-reporting-per-task.md`

## 시점
- 작업 = 사용자 요청 하나, 또는 에이전트가 나눈 하위 작업(태스크·`feature/*` 브랜치) 하나
- 시작 보고: 코드·문서 변경 전
- 종료 보고: 최종 응답 마지막

## 시작 보고 양식
```
### 작업 시작: <작업명> (브랜치 <name>)
| 필요한 결정 | 선택지 | 추천 | 근거 |
관련 미결 결정: <STATUS.md 미결 결정 중 해당 ID, 없으면 "없음">
```
- 사용자 결정이 필요하고 기본값이 없으면 AskUserQuestion으로 질문 후 진행
- 관례적 기본값이 있으면 추천안으로 진행하고 보고에 명시

## 종료 보고 양식
```
### 작업 종료: <작업명>
| 내린 결정 | 근거 | 기록 |   ← 기록 = ADR 번호 또는 "ADR 불필요(사유)"
| 미결 결정 | 필요 시점 | 막는 작업 |   ← 신규·잔존 모두
```

## 기록 반영
- 아키텍처·정책·규약 수준 결정 → `docs/adr/` 추가
- 미결 결정 → `docs/STATUS.md`의 `## 미결 결정` 표 (ID `D-NN`). 해소되면 행 삭제 + ADR 링크를 완료에 기록
- 근거를 모르는 결정은 추측 금지 → `근거 미기록`
