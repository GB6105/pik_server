# 개인정보·삭제·보관

근거: 요구사항 `## 이력과 삭제 정책`, FR-O-02, FR-A-05.

## 로그
- 사진·계정·OCR 본문 전체 기록 금지. ID·상태·사유 코드만

## 외부 AI 전송
- 동의(FR-O-02) 없이 전송 금지. 사진 접근 허용 ≠ 외부 전송 동의
- 거절 시 수동 기능 유지
- 전송 범위·임시 보관 기간·철회: P08 미정

## 데이터 이력
- 변경 가능한 데이터: 생성·수정 시각 + 버전
- 원본 사진·OCR 본문을 영구 이력으로 보관 금지

## 삭제
| 동작 | 처리 |
|---|---|
| 태그 해제·이벤트 사진 제외 | 관계만 제거. 원본 삭제 아님 |
| 동기화용 삭제 표시 | 전달 완료까지 tombstone, 기한 후 제거 |
| 이벤트 완료·숨김 | 삭제 아닌 상태. 알림·삭제 요청 재생성 방지 위해 보존 |
| 권한 철회·다운로드 불가·기기 미보유 | 원본 삭제와 구분 |
| OS 원본 삭제 확인 후 메타데이터 | P11 미정 |

## 탈퇴 (FR-A-05)
- Pik 메타데이터·분석 결과·계정 삭제. OS 사진·앨범은 유지
- soft delete만으로 삭제 완료 표시 금지
- 서버·임시 처리 시스템 미완료분 추적 → 배치로 완료
- 플랫폼 구독 상태는 별도 확인
- 결제 검증·중복 방지용 최소 기록 보존 범위: P08 미정
