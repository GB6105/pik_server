# 개인정보·삭제·보관

근거: 요구사항 `## 이력과 삭제 정책`, FR-O-02, FR-A-05.

## 로그
- 사진·계정·OCR 본문 전체·검색어·앨범 이름 기록 금지. ID·상태·사유 코드만
- 기기 식별자 (ANDROID_ID·DeviceCheck 토큰)·제공자 사용자 ID 원문 기록 금지
- 토큰·`Authorization` 헤더·푸시 토큰·이메일·IP 기록 금지 (ADR-0023)
- 구조화 로그 필드 허용 목록: trace ID, 주체 ID (내부 UUID), 동작, 대상 ID, 상태, 사유 코드, HTTP 상태, 소요 시간 (ADR-0023)

## 외부 AI 전송
- 동의(FR-O-02) 없이 전송 금지. 사진 접근 허용 ≠ 외부 전송 동의
- 거절 시 수동 기능·속성 검색 유지. 사진 분석·자연어 검색 제공 안 함 (ADR-0021)
- 동의 = 단일 동의 + 목적 필드 기록. 철회 시 전송 전 작업 취소, 이미 보낸 요청의 응답 저장 안 함, 기존 결과 유지 (ADR-0021)
- 전송 대상 (ADR-0016): 사진 축소본·OCR 텍스트 (단말 OCR 채택 시, D-09) → Claude / 검색어·앨범 이름 → Jev / Pro 검색어 → Claude. 사진은 Jev로 전송 금지
- 번역 (FR-X-05) = 사진 속 텍스트 → Claude (서버 번역, ADR-0024)
- AI 외 외부 전송: 이벤트 장소 문구 → Google Places (장소 알림 좌표, ADR-0024). 동의 안내에 포함. 지도 액션은 외부 장소 API 미사용 (단말이 지도 앱을 검색어로 엶)
- 동의 안내에 국외 이전 고지 포함
- 분석용 임시 이미지(S3) = 처리 후 즉시 삭제 + 만료 규칙
- 임시 보관 기간: P08 미정

## 인증·요청 기록
- 멱등 기록 (응답 본문 포함) = 7일 (설정값) 후 삭제, 탈퇴 시 즉시 삭제 (ADR-0023)
- 익명 설치 토큰 = 만료 없음. 장기 미사용 설치의 보관 기준은 P08 비로그인 데이터 보관 기한과 함께 결정

## 데이터 이력
- 변경 가능한 데이터: 생성·수정 시각 + 버전
- 원본 사진·OCR 본문을 영구 이력으로 보관 금지

## 파생·외부 데이터 보관 (ADR-0024)
- 유사도 벡터 (`photo_vector`) = 사진이 있는 동안 보관. 사진 삭제·탈퇴 때 함께 삭제. 비로그인 주체는 다른 비로그인 서버 데이터와 같이 P08 기한에 삭제
- Google 장소 좌표 = 조회 후 30일 이내만 보관, 기한 전에 `place_id`로 갱신, 갱신 못 하면 좌표 삭제. `place_id`는 계속 보관 (Google 약관). 갱신 대상 = 장소 알림 예약이 있는 ACTIVE 이벤트만, 그 밖의 이벤트는 기한에 좌표 삭제. 동의 철회 시 갱신 중단. 단말 사본 (비로그인 좌표, OS 지오펜스·위치 알림)도 같은 기한, 갱신 못 하면 좌표와 등록 삭제
- 카카오 로컬 API 결과는 저장 금지 (카카오 정책) → 사용하지 않음
- 알림 기기별 발송 기록 (`notification_delivery`)·API 호출 제한 카운터 (`api_rate_counter`) = 보관 기간 (P08 설정값) 후 삭제

## 삭제
| 동작 | 처리 |
|---|---|
| 태그 해제·이벤트 사진 제외 | 관계 제거. 원본 삭제 아님. 이벤트 사진 제외는 `EXCLUDED` 표시로 남겨 자동 재연결 차단 (요구사항 67·1175행, ADR-0022) |
| 동기화용 삭제 표시 | 전달 완료까지 tombstone, 기한 후 제거 |
| 이벤트 완료·숨김 | 삭제 아닌 상태. 알림·삭제 요청 재생성 방지 위해 보존 |
| 권한 철회·다운로드 불가·기기 미보유 | 원본 삭제와 구분 |
| OS 원본 삭제 확인 후 메타데이터 | '원본 없음' 상태 보존 → 보관 기간 (설정값) 후 삭제. 최근 삭제 복구 시 재연결 (ADR-0021). 대표였으면 삭제 확인 때 새 대표를 고르고, 결과가 가리키는 `analysis_job` 행은 메타데이터 삭제 뒤에도 유지 (ADR-0024 #6-3) |

## 탈퇴 (FR-A-05)
- Pik 메타데이터·분석 결과·유사도 벡터·계정·멱등 기록·refresh 토큰 삭제. OS 사진·앨범은 유지
- soft delete만으로 삭제 완료 표시 금지
- 서버·임시 처리 시스템 미완료분 추적 → 배치로 완료
- 플랫폼 구독 상태는 별도 확인. RevenueCat 고객 삭제 포함 (ADR-0018)
- 탈퇴 후 최소 기록 (ADR-0020): 내부 계정 ID·탈퇴 일시·삭제 작업 상태·처리한 결제 이벤트 ID와 종류·제공자 사용자 ID 해시. 결제 이벤트 본문은 삭제. 보관 기간 = 설정값 (법령 검토 전)
- 기기 판별 기록·재가입 판별 해시는 탈퇴 후에도 유지, 계정 데이터와 분리 저장. 재가입 판별 해시는 가입 시 저장. 원본 식별자 저장 금지, 서버 비밀 키 HMAC만 저장 (ADR-0021)
