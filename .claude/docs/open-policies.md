# 미정 정책 (P01~P12)

근거: 요구사항 `# 미정 정책과 기술 검증`.

## 규칙
- 미정 값은 하드코딩 금지 → `application.yml` 설정값 + 기본값은 현재 초안
- 확정 전 인수 조건이 불완전한 FR은 TODO가 아니라 열린 질문으로 보고
- 확정되면 이 표와 관련 설정값 갱신

## 서버 영향 정책
| ID | 미정 내용 | 서버 영향 FR | 현재 초안 |
|---|---|---|---|
| P01 | 100장 집계 기준, 실패·재사용 차감, 3회 클릭 중복 집계 | FR-I-01~03, FR-B-01 | 대표+구성 사진 합산 100장. 일부 확정 (ADR-0021): 접수 시 예약·실패 시 반환·재분석 미차감, 기기·계정 이중 집계. 미정: 체험 사진 교체, 3회 클릭 집계 |

| P03 | Pro 가격·분석량·처리 시간·재시도, 만료 후 비용 | FR-I, FR-X-05~06, FR-B | 없음 |

| P07 | 기기 간 사진 식별, 게스트·계정 충돌, 병합 | FR-A-01~04 | 일부 확정 (ADR-0020): 확인 후 귀속·충돌 시 서버 값 유지, 제공자별 별도 계정, 로그아웃 시 기기 데이터 제거, 기기 간 같은 사진 = iCloud 동기화 사진만 (ADR-0022). 미정: PHCloudIdentifier 신뢰성·재설치 복원 방법 (FR-A-04 기술 검증), 정리 세션 복원 |

| P09 | 알림 선행 시간·반복·정리 알림 단계 | FR-E, FR-N | 정리 알림 1·2·3·5·7·14일 |
| P10 | 태그·메모 길이, 검색 페이지 크기·조건 | FR-L, FR-S | 없음 |
