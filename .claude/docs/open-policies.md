# 미정 정책 (P01~P12)

근거: 요구사항 `# 미정 정책과 기술 검증`.

## 규칙
- 미정 값은 하드코딩 금지 → `application.yml` 설정값 + 기본값은 현재 초안
- 확정 전 인수 조건이 불완전한 FR은 TODO가 아니라 열린 질문으로 보고
- 확정되면 이 표와 관련 설정값 갱신
