# FR 서버 구현 범위

근거: 요구사항 각 FR의 `호출:` 항목.

## 서버 전담
| 영역 | FR | 서버 역할 |
|---|---|---|
| 계정과 데이터 | FR-A-01~05 | Apple·Google 로그인, 게스트 정보 귀속, 로그아웃, 계정 정보 복원, 탈퇴 삭제 |
| 무료 체험·구독 | FR-B-01~05 | 체험 대상·클릭 집계, 구독 상태 조회, 구매 검증·복원·플랫폼 상태 변경 수신 (RevenueCat 경유, ADR-0018), 기능 제한 |
| 권한과 동의 | FR-O-02 | 외부 AI 분석 전송 동의 기록 |

## 단말·서버 공동 (서버 부분만 구현)
| 영역 | FR | 서버 부분 |
|---|---|---|
| 자동 생성 | FR-G-01~04 | 분석 작업 접수, 분석 완료 이벤트 → 액션·이벤트 생성·저장. 비로그인 이벤트는 단말이 보낸 기존 이벤트 요약으로 판단만 하고 저장 안 함 (ADR-0024) |
| 분석·추천 | FR-I-01~06 | 작업 등록, 묶음·대표 선정, OCR·의도 분석, 파생 정보 갱신, 추천·진행 상태 조회 |
| 검색 | FR-S-01~04 | 자연어 → 검색 계획 해석 (Jev 폴더 가중치·날짜·Pro 속성 추출). 검색·묶음 조회·일괄 작업 실행은 단말, 서버는 메타데이터 동기화만 (ADR-0017) |
| 액션 | FR-X-03, 05, 06 | 지도 = 장소 문구·주소 확정만 (지도 앱 연결은 단말, 외부 장소 API 미사용), 번역 (Claude Haiku), 웹페이지 후보 탐색 (ADR-0024) |
| 메타데이터 | FR-L-05 | 로그인 사용자의 메모·태그 동기화 |
| 이벤트 | FR-E-01~04 | 로그인 사용자의 이벤트 생성·조회·수정·완료 동기화 |
| 알림 | FR-N-02~04 | 로그인 사용자: 이벤트 시간·정리 독려·권한 요청 알림을 서버가 판단해 FCM 발송, 장소 알림은 표시 전 서버 확인. 발송 대상 = 계정의 모든 기기, 장소 좌표 = 서버 Google Places (ADR-0024). 비로그인: 단말 예약 (ADR-0019) |
