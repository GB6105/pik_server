# 승인된 SSOT 차이·해석

근거: `docs/adr/0030-design-review-r1-corrections.md` #7

## 규칙
- 아래 항목은 사용자가 승인한 SSOT와의 차이 또는 SSOT 해석. `docs/spec`는 수정하지 않음
- 인수 조건·테스트 작성 = SSOT 원문 + 이 표를 함께 확인. 표에 없는 차이는 사용자에게 보고
- 새 차이·해석을 ADR에 기록하면 이 표에 행 추가
